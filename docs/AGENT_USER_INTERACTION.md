# Agent 与用户异步协作闭环

## 目标

用户不需要守在长任务旁等待。工作流持续运行并保存阶段产物，用户可以在任意时间返回，针对明确对象讨论、审批修改，并在后台重算完成后审阅候选版本。

## 作用域

每次讨论固定绑定：

`task_id + report_id + artifact_type + artifact_version + object_id`

可讨论对象覆盖任务目标、材料角色、分析规划、事实、分析判断、最终目录、叙事计划、质量问题、报告题目、章节标题和正文句子。对话不会脱离当前对象形成无边界的通用聊天。

## 修改分级

| 类型 | 处理方式 | 用户结果 |
|---|---|---|
| 未运行任务的目标与要求 | 直接更新任务上下文 | 下一阶段使用新要求 |
| 报告题目、章节标题、正文句子 | 确定性应用并生成小版本 | 可立即查看和回滚 |
| 材料角色、规划、事实、推论、叙事、质量问题 | 保存提案并后台重算 | 生成候选版本后审阅差异 |

事实与推论不允许作为普通文本直接覆盖。事实疑问回到 Evidence，推论疑问回到 Analysis，目录问题回到 Final Plan，叙事与语言问题回到 Narrative Plan 或 Writer。

## 异步状态

`提案待确认 → 等待当前轮次结束 → 已排队 → 后台重算 → 候选版本已生成 → 版本审阅`

多条待处理提案会合并为一个后台轮次，并从最早受影响阶段开始重算，避免重复运行。后台失败会保留基线版本、错误信息和提案，不会静默覆盖报告。

## 版本原则

语义重算前自动生成不可变基线快照。Writer 对受影响章节执行原子替换，重算结束生成候选版本。用户在版本审阅中按章节、段落或句子决定保留新内容或恢复原内容，最终报告仍由用户验收。

## 产品入口

- 任务工作台“协作审阅”：浏览所有阶段产物、搜索对象、讨论并审批提案。
- 报告编辑器“讨论”：点击报告题目、章节标题或正文句子进入对应作用域。
- 协作通知：显示提案排队、候选版本完成和失败状态，并跳转到任务或版本审阅。
