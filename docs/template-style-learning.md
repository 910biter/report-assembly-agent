# 模板与软风格学习架构

## 1. 目标

模板系统同时解决两类不同问题，但两者不得互相替代：

- 原始 DOCX + Template Schema：确定页面、字体、段落、标题层级、编号、表格和页眉页脚等版式。
- Editorial Style Profile：描述历史成品如何组织语言、推进信息、使用材料和形成分析。

当前方案不训练或微调模型，采用结构化画像、运行时样例检索、受约束生成和只读风格诊断。

## 2. 系统边界

风格能力只作用于 Narrative Plan 之后的语言实现，不参与以下决策：

- Fact 是否成立及其重要性；
- Evidence 与原始 Unit 的绑定；
- Inference 的依据链；
- 章节事实选择和证据充分性；
- 报告目标规模与安全上限。

风格学习或检索失败时，Writer 按正常事实链继续工作，不得阻断可审核报告。

## 3. 学习流程

```text
DOCX 模板 ----------------------> Template Schema ------> DOCX Renderer

历史审核成品
  -> 标题与自然段分割
  -> 跨章节覆盖采样
  -> 可解释统计特征
  -> LLM 归纳表达规律与段落用途
  -> Style Profile + Exemplar Bank
```

学习器版本参与缓存身份。学习算法升级后，同一源文件会重新生成画像，不会静默复用旧结果。

## 4. 结构化画像

Style Profile 固定结构、动态取值，主要包含：

- `writing_style`：语气、句式和分析风格；
- `writing_patterns`：信息推进、段内组织、句子节奏、衔接、具体程度、立场与情态；
- `observed_metrics`：段落长度、每段句数、句长和标点分布；
- `chapter_styles`：不同章节功能对应的表达目的；
- `terminology`：惯用和避免表达；
- `material_realization`：主次事实选择、具体信息保留、多来源综合、事实到判断和证据边界表达；
- `exemplar_bank`：带来源、章节、位置、用途和审核状态的段落级样例；
- `profile_confidence`：各层画像独立置信度；
- `structure_policy`：`FORMAT_ONLY / SOFT_STRUCTURE / HARD_STRUCTURE`。

画像不得把历史报告中的具体业务事实固化为通用规则。

## 5. 运行时执行

```text
Final Report Plan
  -> Narrative Plan 明确章节/小节目的和 discourse role
  -> 按目的、角色、报告类型和章节上下文检索 1-3 条样例
  -> 对来源和章节做多样性控制
  -> Writer 接收事实、推论、Narrative Plan、短 Style Card 和匹配样例
  -> 正文继续逐句绑定 fact_ids / inference_ids
  -> 保存只读 Style Diagnostic
```

样例检索不会把历史样例中的事实加入当前报告，只允许借鉴组织和表达方式。匹配度不足时宁可少给样例，不用无关范例凑数量。

## 6. 原模板执行协议

编译器从 OOXML 直接读取页面、样式继承、多级编号、标题层级、段落格式和角色锚点。Schema 中的 `render_contract` 记录标题替换位置和正文插入位置，导出器在原始 DOCX 内执行，而不是另建空白 Word 模仿模板。

- 报告始终优先使用创建时绑定的模板，默认模板不能静默替换它；
- 编号读取 `numbering.xml` 的 `numFmt/lvlText/start/suff/ilvl`，可见文字只作兜底；
- 未明确识别的书名、文件名不会被误当成占位符；
- 模板示例目录默认不进入内容规划，当前任务仍由 Fact、Inference 和用户目标决定结构；
- 旧格式兼容字段只作读取兜底，不再覆盖新版 Template Schema。

## 7. QA 与修复边界

Style Diagnostic 比较成文与画像的统计节奏、术语和表达偏差，只生成诊断：

- 不自动修改事实；
- 不自动更换引用；
- 不自动重组章节；
- 不因风格偏差阻断报告进入审核。

后续如启用局部修复，只允许对被标记段落定点重写，并在原 fact_ids/inference_ids 范围内重新校验。

## 8. 验收指标

- 学习覆盖：来源报告数、章节覆盖数、自然段样本数；
- 画像稳定性：同批输入重复学习后的字段一致性；
- 检索质量：章节目的匹配率、无关样例率、来源多样性；
- 执行效果：风格诊断分、禁用术语命中、段落/句子分布偏差；
- 内容红线：Fact 使用率、引用有效率、溯源完整率不得下降；
- 性能：每个小节仅注入少量样例，列表 API 不返回完整样例库。

真实效果最终需要使用同一材料、同一 Final Plan 对比无风格增强和新画像增强的报告，由人工盲评语言相似度、可读性和事实保持情况。
